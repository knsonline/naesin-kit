저장한 테마 파일을 다음 시험 때 불러오면 같은 디자인으로 바로 만들 수 있어요.

시험지로 블로그와 카드뉴스 만들기

ChatGPT나 Claude 채팅만 있으면 됩니다. 시험지와 결과는 이 화면 밖으로 나가지 않아요.

  1. 학원 정보 적기 비워 두면 '우리 학원'으로 써요

  2. 프롬프트 복사해서 채팅에 보내기

    ChatGPT나 Claude에서 새 대화를 열고 시험지 PDF를 첨부한 뒤, 복사한 프롬프트를 붙여 넣어 보내세요. 생각(추론) 모드가 있으면 켜 주세요.

  3. AI가 준 결과 붙여 넣기

    AI 답의 코드 블록 전체를 복사해서 아래에 붙여 넣으세요. 코드 블록 오른쪽 위의 복사 버튼을 쓰면 편해요.

  4. 고칠 곳이 있으면 AI에게 다시 보내기

    점검에서 고칠 곳이 나오면 수정 요청을 복사해 같은 대화에 붙여 넣으세요. 새 결과가 오면 3번부터 다시 하면 됩니다. 보통 한두 번이면 끝나요.

  5. 카드와 블로그 꾸미고 올리기

    카드뉴스 탭에서 학원 색과 스타일을 고르고 저장하세요. 블로그 탭에서 제목과 본문을 복사해 네이버 블로그에 붙여 넣으면 됩니다.

자동으로 만들고 싶다면

Claude 유료 플랜(Pro 이상)이 있으면 Claude Code가 시험지를 읽고, 점검하고, 고치는 과정을 혼자 반복합니다. 붙여 넣기가 필요 없고 결과가 가장 좋아요.

  1. 키트를 내려받아 압축을 풉니다.
  2. Claude 앱 → Code 탭에서 키트 폴더를 엽니다.
  3. "시험지로 블로그랑 카드뉴스 만들어 줘"라고 입력합니다.
키트 내려받기 (ZIP)

지금 키트 폴더에서 열려 있어요. 자세한 방법은 폴더의 시작하기.md를 보세요.
